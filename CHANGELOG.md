# Release notes

## 1.0.0 — 2026-11-22

First release. What is in it:

* Anonymous request cache with publish/comment invalidation
* Bulk conversion with per-attachment tracking
* Redirect table with cache purge on change
* Open Graph and Twitter cards with image fallback
* Weekly table optimisation with per-table size report
* Async image decoding with fetch priority on the hero image
* REST purge route behind capability checks
* Runtime snapshot view before send
* Settings export and validated import

Nothing was removed or deprecated, because nothing existed before this tag.
